# 💸 Expense Tracker

A modern and interactive **Expense Tracker Web App** built using **HTML, CSS, and JavaScript**.
This project helps users manage daily expenses, visualize spending patterns, and maintain financial awareness — all within a clean and responsive UI.

---

## 🚀 Features

* ➕ Add expenses with title, amount, and category
* 🗑️ Delete expenses dynamically
* 💰 Real-time total expense calculation
* 📊 Category-wise expense visualization (custom chart)
* 💾 Persistent data using Local Storage
* 🎨 Modern UI with glassmorphism and gradient effects
* ⚡ Smooth animations and interactive elements

---

## 🧠 Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling (Glassmorphism + Gradient UI)
* **JavaScript (Vanilla)** – Logic & State Management
* **Local Storage API** – Data persistence

---

## ⚙️ How It Works

1. User enters expense details (title, amount, category)
2. Data is stored in a JavaScript array
3. Expenses are saved in **localStorage**
4. UI updates dynamically:

   * Expense list
   * Total amount
   * Category-based chart

---
## 🛡️ Validations & Edge Cases

- Prevents empty input submission  
- Ensures amount is greater than zero  
- Handles empty state (no expenses added)  
- Safely updates UI after deletion  
---

## 📊 Chart Logic

The app generates a **custom bar chart** based on category-wise spending:

* Calculates total per category
* Converts values into percentage
* Dynamically renders animated bars
